# Datheon Machine Learning & Data Science Internship

## Task 1: Iris Flower Classification

### Objective
Build and compare supervised classification models
using the Iris dataset.

### Models
- Logistic Regression
- Decision Tree Classifier

### Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Jupyter Notebook

### Workflow
1. Dataset exploration and visualization
2. Train-test split (80/20)
3. Feature scaling with StandardScaler
4. Model training and evaluation
5. Confusion matrix heatmaps
6. Decision boundary visualization

### Project Structure
- `data/`: Iris dataset
- `notebooks/`: Task 1 notebook
- `requirements.txt`: Required libraries

### How to Run
Install the requirements:

```bash
pip install -r requirements.txt
```

Open the notebook in Jupyter and run the cells
from top to bottom.

### Results
Model performance metrics are reported in the notebook.
